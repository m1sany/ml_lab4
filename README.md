# Лабораторная работа № 4

## Запуск приложения

Нужен Python 3.10 или новее. Распакуйте архив и откройте терминал в папке lab4.

```bash
python -m venv .venv
```

Windows: `.venv\Scripts\activate`

macOS/Linux: `source .venv/bin/activate`

```bash
python -m pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Откройте http://127.0.0.1:8000. Остановка сервера: Ctrl+C.
Веса уже обучены. Приложение читает оба JSON при старте; при отправке формы обучения нет.

## Файлы

- Ноутбук `.ipynb`: исходная лабораторная, обучение обеих сетей, метрики, проверка сохранения/загрузки, примеры и создание архива приложения. Откройте в Google Colab и выполните ячейки сверху вниз. Для локального обучения нужны дополнительно numpy и scikit-learn.
- `models.py`: исходная сеть 4 → 8 → 3 и регрессия 3 → 8 → 1 с линейным выходом.
- `main.py`: FastAPI, загрузка моделей при старте, GET/POST обеих форм.
- `templates/form.html`: серверный шаблон Jinja2 для двух страниц.
- `iris_weights.json`, `regression_weights.json`: веса, смещения и параметры нормализации.
- `test_app.py`: проверка HTML-ответов, трёх примеров каждой задачи и некорректного ввода. Для запуска установите `httpx`: `python -m pip install httpx`, затем `python test_app.py`.
- `SCREENCAST.md`: сценарий записи обязательного видео.

## Результаты выполненного обучения

Разбиение: 120 объектов для обучения, 30 для теста, seed=42. Минимумы и максимумы рассчитаны только по обучающей части.

Классификация: 29 верных ответов из 30, accuracy = 96,67%.
Регрессия: MAE = 0,2223 см; константный прогноз средним по обучению: MAE = 1,7577 см.
Это результаты одного фиксированного разбиения небольшого набора данных, а не оценка на всех возможных цветках.

В регрессии входы — длина чашелистика, ширина чашелистика, ширина лепестка. Цель — длина лепестка в сантиметрах; на вход она не подаётся. Выход ровно один, линейный, без argmax. Цель не нормализуется, поэтому обратное преобразование выхода не нужно.

Выходы обеих моделей до/после JSON совпали на всех тестовых объектах. Проверки FastAPI выполнены через TestClient без внешнего сервера. Браузерная видеозапись не создана: установка браузера в среде выполнения оказалась недоступна.

Документация: https://fastapi.tiangolo.com/advanced/templates/ и https://fastapi.tiangolo.com/tutorial/request-forms/.
